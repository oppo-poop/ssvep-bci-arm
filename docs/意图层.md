# 意图层：SSVEP → 机械臂动作

> 第一版目标（2026-10-18 定）：**不碰视觉，先用 SSVEP 类别直接驱动机械臂**，验证"脑控"这条链路能闭合。
> 视觉检测与"检测框即刺激"是第二步，见 `素材/01-项目与场景.md` §三。

## 一、链路

```
SSVEP 解码（复用 ssvep-bci 的 CCA/FBCCA）
     ↓ 每判定一次，吐一个类别 k（+ 可选置信度）
scripts/intent_bridge.py
     ↓ 查映射表，转成 roarm_cli 的子命令
roarm_cli.py  →  arm_moveit_write  →  move_group  →  cello_controller  →  舵机
     ↓ TF 实测到位校验，退出码 0/1/2
     ↓ 有反馈，再判下一次
```

**为什么中间要加一层桥，而不是让解码器直接发 ROS 指令**：

1. 解耦。解码器不知道机械臂存在，它只管吐类别；换执行端（比如换成小车）不用改解码
2. 可离线验证。没有脑电硬件时，用 `--replay` 喂一串类别就能测完整链路
3. 冷却与过滤逻辑有地方放（置信度、连续判定去重）

## 二、为什么不照抄 `drive_pilot.py`

| | 小车（`drive_pilot`） | 机械臂（本层） |
|---|---|---|
| 控制对象 | 持续速度 | 离散目标位姿 |
| 注视语义 | 持续注视 = 持续运动 | 单次判定 = 执行一次 |
| 误判后果 | 车继续走，松眼即停 | 臂走到错误位置，需要回位 |
| 结束条件 | 停止块 / 松眼 | 到达目标即结束 |

所以机械臂这侧是**事件驱动**：判定一次 → 执行一次 → 回到待判定状态。
不能做成"盯着就一直走"，否则误判会累积。

## 三、类别映射（第一版）

索引与 `ssvep-bci/config.py` 的 `FREQS` 对齐：

| k | 频率 | 名字 | 机械臂动作 | 备注 |
|---|---|---|---|---|
| 0 | 15.0 Hz | home | `home` | 已验证 |
| 1 | 16.5 Hz | up | `up` | 已验证 |
| 2 | 18.33 Hz | right | `right` | 已验证 |
| 3 | 20.625 Hz | safe | `pose 0.45 0 0.40` | 已验证，误差 4.92 mm |
| 4 | 13.75 Hz | stop | 不动作 | 停止块 |

**为什么第一版不选 `start`**：`(0.33, −0.324, 0.154)` 对应 j5 = −68.9°，限位 ±90°，
腕部只剩 21° 余量。第一版要排除一切非必要风险。

**为什么用路点而不是具体动作**：先证明"识别 → 执行"闭环成立，动作语义是第二步的事。

## 四、输入格式

从 stdin 逐行读，一行一条：

```
0            # 只给类别
1 0.82       # 类别 + 置信度（低于 --conf-min 丢弃）
```

`--replay "0,1,0,2"` 可直接回放，用于**没有脑电硬件时验证链路**。

过滤规则：
- 置信度 < `--conf-min`（默认 0.30）→ 丢弃
- 未知类别（不在表里）→ 丢弃
- 无法解析的行 → 丢弃
- 类别 4（停止块）→ 不动作，但不报错

## 五、怎么接真实解码器

需要 `ssvep-bci` 提供一个**无 GUI 的 stdout 模式**，每判定一次打印一行 `<k> <conf>`。

现状（2026-10-18 核查）：`ssvep-bci` 有 `realtime.py`（506 行，带 GUI）和
`drive_pilot.py`（177 行，无头自检 18/18），但**没有面向 stdout 的输出模式**。

两条路：
1. 给 `realtime.py` 加 `--headless`，判定后 `print(k, conf, flush=True)`
2. 直接复用 `drive_pilot` 的判定循环，把 `send` 换成 `print`

第 2 条更省，因为 `drive_pilot` 已经是无头的。

## 七、与视觉版的关系

视觉版上线后，类别不再是"路点"，而是"检测框编号"：

```
视觉检测 N 个目标 → 分配 N 个频率 → SSVEP 判 k → 第 k 个框
     ↓ 该框的 3D 位置
Scene(pick=框位置, place=默认放置点) → roarm_task
```

**本层的映射表会被替换，但过滤、冷却、反馈这些机制不变**。所以先做这版不浪费。
