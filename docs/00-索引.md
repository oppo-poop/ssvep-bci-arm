## 四、脚本

所有脚本在 `scripts/`，都用 `--help` 自解释。

| 脚本 | 用途 | 会动机器吗 |
|---|---|---|
| `robot_up.sh` | 真机一键启动（driver → move_group → 执行节点） | ✅ 启动时会回零 |
| `sim_up.sh` | 仿真一键起停（含夹爪桥） | ❌ 只动仿真 |
| `roarm_cli.py` | 终端控臂 + TF 到位校验 | ✅ |
| `roarm_task`（包） | `ros2 run roarm_task task` 取放序列 | ✅ |
| `zero_calib.py` | 只读测量舵机角度，零位标定 | ❌ 只读（`--free` 除外） |
| `go_zero.py` | 逐步驱到零位/收纳位，可解锁 | ✅ |
| `fk.py` | URDF 正运动学，关节角 → 末端位置 | ❌ 纯计算 |
| `sim_test.py` | 16 项场景矩阵 | ❌ 只动仿真 |
| `sim_gripper_bridge.py` | 仿真专用夹爪桥 | ❌ 只动仿真 |
