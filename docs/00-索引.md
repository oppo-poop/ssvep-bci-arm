## 四、脚本

入口索引见 [`../scripts/README.md`](../scripts/README.md)。下表是常用项；旧路径仍可用。

| 脚本 | 用途 | 会动机器吗 |
|---|---|---|
| `robot_up.sh` | 真机一键启动（driver → move_group → 执行节点） | ✅ 启动时会回零 |
| `sim_up.sh` | 仿真一键起停（含夹爪桥） | ❌ 只动仿真 |
| `roarm_cli.py` | 终端控臂 + TF 到位校验（唯一契约） | ✅ |
| `roarm_task`（包） | `ros2 run roarm_task task` 取放序列 | ✅ |
| `calib/zero_calib.py` | 只读测量舵机角度，零位标定 | ❌ 只读（`--free` 除外） |
| `calib/go_zero.py` | 逐步驱到零位/收纳位，可解锁 | ✅ |
| `roarm_lib/fk.py` | URDF 正运动学，关节角 → 末端位置 | ❌ 纯计算 |
| `checks/sim_test.py` | 16 项场景矩阵 | ❌ 只动仿真 |
| `sim_gripper_bridge.py` | 仿真专用夹爪桥 | ❌ 只动仿真 |
| `teach.py` | 交互示教：微调摆位 → 记录点位 → 生成场景 yaml | ✅ |
| `calib/repeatability.py` | 重复定位精度（TF / FK 双口径，`--settle` 静置复测） | ✅ |
| `calib/limit_probe.py` | 逐关节行程实测（`--free-all` 全解锁逐关节掰） | ✅ 单关节解锁 |
| `run_task.sh` | 取放连跑 N 次，日志带时间戳 + `data/runs/summary.csv` 汇总 | ✅ |
| `intent_bridge.py` | 调试用点位桥（`--status` 读 `ssvep-bci/run_status.json`、`--replay`） | ✅ |
| `checks/grip_check.py` | 夹爪口径/零位/启动位与 `config/robot.json` 一致性 | ❌ |
| `checks/pick_check.py` | 视觉边界、落点补偿、参数单源回归 | ❌ |
| `checks/traj_check.py` | 轨迹下发/取消保持/joint7 端点换算 | ❌ |
| `check_all.sh` | 一键跑全部离线检查 | ❌ |
