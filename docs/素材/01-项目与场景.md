# 项目与场景

## 一、一句话定位

面向轮椅 / 床旁失能人群的**脑控辅助取物机械臂**：用眼动完成目标粗选，用 SSVEP 做确认 / 取消 / 急停，
机械臂以任务级宏指令半自主执行。

## 二、使用场景

| 维度 | 描述 |
|---|---|
| 使用者 | 上肢运动功能受损、但具备基本视觉与注意能力的人群（脊髓损伤、脑卒中后遗症、渐冻症早中期） |
| 环境 | 轮椅旁 / 床边，桌面上放置日常物品（水杯、药盒、遥控器） |
| 任务 | 从桌面上抓取指定物体并递送到使用者手边 |
| 交互约束 | **不能依赖手部操作**；认知负荷要低（疲劳会显著降低 SSVEP 识别率） |
| 安全约束 | 机械臂在人身旁工作，必须有可被使用者随时触发的停止手段 |

## 三、技术路线

### 当前方案：视觉检测即刺激（2026-10-18 定）

```
摄像头采集场景
     ↓
YOLO / 传统 CV 检测目标物 → 每个目标画一个矩形框
     ↓
矩形框本身作为 SSVEP 闪烁刺激（每框分配一个频率）
     ↓
人眼注视想拿的那个框
     ↓
SSVEP 解码 → 判断注视哪个框 → 得到目标
     ↓
2D 框 → 3D 抓取位姿 → Scene → 任务层 → 机械臂
```

**核心思路**：检测结果**直接变成刺激**——看到什么就盯什么，眼里看到的框和闪的框是同一个。

### 为什么放弃眼动（暂缓，不是永久）

原方案是「眼动粗选目标 + SSVEP 3 类确认」。改为现在的方案，原因有三：

| 原方案问题 | 现方案怎么解 |
|---|---|
| Tobii / Gazepoint / 七鑫易维在 Linux 全不支持，可用方案只有 USB 相机 + L2CS-Net（精度有限） | 一条摄像头链路同时承担检测和交互，不需要眼动硬件 |
| 两套模态要分别标定、分别调参 | 单一模态，链路短 |
| 眼动给"看哪里"，但物体位置还得再映射一次 | 检测框本身就是物体位置，映射只做一次（2D→3D） |

眼动留作后续增强（如果单模态的误触发率不可接受）。

### 由此产生的技术后果（必须正视）

1. **SSVEP 类别数 = 当前检测到的目标数**，是**动态**的，不再固定
   传统 SSVEP 用固定网格，参考信号数量恒定；这里每次场景变化都要重建分类器

2. **刺激位置会变**
   检测框随物体移动而移动。传统研究全部用固定位置刺激，
   **"动态位置 + 固定频率"对 SSVEP 质量的影响是本项目必须实测的未知数**

3. **框抖动会变成刺激抖动**
   逐帧检测必然抖动，闪烁块跟着抖会引入额外的视觉噪声与运动伪迹

4. **取消 / 急停仍需要独立通道**
   不能只靠"盯某个目标"，否则出错时无法中止

### 已定的关键设计

- **闪烁框的位置：冻结**（2026-10-18 定）
  检测一次 → 框位置冻结 N 秒 → 在这段时间内闪烁、采集、判决。
  理由：跟随式会同时引入"检测抖动"和"动态刺激"两个未知量，出问题分不清是哪个。
  冻结版也更接近传统 SSVEP 的实验条件，可以直接搬 `ssvep-bci` 的 1.5 s 窗与 FBCCA 参数做对照。
- 频率分配：绑定物体（物体 A 恒为 8 Hz）还是绑定位置？
- 目标数上限：同时最多允许多少个框（类别数直接影响准确率）
- 取消 / 急停：固定角落的闪烁块，还是物理按钮

### 关于"两级确认"的说明

原方案的"两级"（眼动粗选 + SSVEP 确认）在当前方案里合并成了一级：
**SSVEP 直接选目标**。这削弱了"共享控制"的叙事，
但换来的是**更短的操作链路**——对疲劳耐受差的使用者，这是实打实的好处。

创新点的表述要相应调整，见 `05-创新点.md`。

### 为什么是任务级而不是关节级

不论用哪种选目标方式，人机分工的原则不变：**人决定"要什么"，机器决定"怎么拿到"**。
关节级连续控制受限于脑机接口带宽（每秒最多几个决策），不可行。

## 四、目标用户的真实约束（写申报书时要用到）

| 约束 | 对设计的影响 |
|---|---|
| 手不能动 | 全流程无手部输入；急停也必须是非接触式 |
| 可能长期卧床，视线角度受限 | 屏幕不能假设正前方；需要考虑支架安装 |
| 疲劳耐受差 | 单次任务的操作次数要少；不能要求长时间注视 |
| 对误动作高度敏感 | 必须有"取消"；机械臂速度要可调低 |

## 五、与同类方案的角度差异

> ⚠ **本节是空的。** 申报书的"国内外研究现状"必须引文献与产品，目前没有做调研。
> 需要补：5~10 篇（脑控机械臂 / 共享控制 / SSVEP 应用），以及商用辅助机器人（如 Kinova、Jac o 等）的方案对比。

可以预判的差异点（待文献验证）：

1. 多数脑控机械臂研究停留在"离线分类 + 仿真"，本项目做到**真机闭环 + 可复现测试**
2. 多数方案用**固定网格** SSVEP 刺激（需先学会"第几行第几列对应什么"），
   本项目把**检测框直接当刺激**，看到什么盯什么
3. 开源软硬件栈（ROS 2 + 商用从臂），成本远低于专用康复机器人
