# 系统架构

## 一、硬件

| 部件 | 型号 / 规格 | 备注 |
|---|---|---|
| 机械臂 | Starai Cello，6 轴 + 平行夹爪 | 从臂 |
| 通信适配 | UC-01 USB 转总线（CH340，`1a86:7523`） | `/dev/ttyUSB0` |
| 舵机总线 | 6 个关节舵机 + 1 个夹爪舵机，ID 0~6 | 波特率 **1 Mbaud** |
| 主控 | x86 笔记本（开发期）→ 目标形态为嵌入式板卡 | 见"待补" |
| 电源 | 舵机独立供电 | 待补规格 |

**几何参数**（URDF 正运动学得出，与真机 TF 实测吻合至 0.5 mm）：

- 零位末端：前方 479.6 mm、高 370.5 mm，距 base 606.0 mm
- 连杆：link2→link3 247.6 mm，link3→link4 267.1 mm，link5→link6 170.7 mm
- 关节限位：j1/j4/j6 ±130°，j2/j3/j5 ±90°
- 夹爪：prismatic 0 ~ −25 mm，对应两指间距 0 ~ 50 mm

## 二、软件分层

### 位置控制链路（主链）

```
① 意图层（未实现）
     眼动选目标 + SSVEP 3 类确认
     ↓ 产出 Scene(pick, place, 物高, 物宽)
② 任务层  roarm_task
     scene.py → sequence.py（10 阶段）→ primitives.py（7 原语）
     ↓ 子进程调用
③ 执行层  scripts/roarm_cli.py
     发 position_orientation_topic + TF 实测到位校验 + 三档退出码
     ↓ 话题
④ 规划客户端  arm_moveit_write
     MoveIt MoveGroupInterface，setPoseTarget + plan + execute
     ↓ action: /move_group
⑤ 规划器  move_group
     OMPL 采样规划 + KDL 逆解
     ↓ action: arm_controller/follow_joint_trajectory
⑥ 控制器  cello_controller
     轨迹点 → 舵机角度（rad→deg），每点加 400 ms 提前量
     ↓ 话题 set_angle_topic
⑦ 总线驱动  robo_driver
     零位偏移补偿 → 同步多圈角度指令
     ↓ 串口 1 Mbaud
⑧ 舵机 0~6
```

### 夹爪链路（分叉）

```
arm_moveit_write ──gripper_command_topic──→ robo_driver ──→ 舵机 6
```

夹爪**不走 MoveIt**（SRDF 里 `hand` 组只有 link 没有 joint，规划不了），直接发话题。

### 仿真与真机的差异

| | 真机 | 仿真 |
|---|---|---|
| ⑥⑦ 层 | `cello_controller` + `robo_driver` | `ros2_control` 的 `FakeSystem` |
| 夹爪 | `robo_driver` 直接订阅话题 | 需 `sim_gripper_bridge.py` 转成 `hand_controller` 的 `GripperCommand` 动作 |
| 动力学 | 有（重力、死区、背隙） | 无，瞬时就位 |
| 碰撞 | 有 | 无（`sensors_3d` 置空，场景无物体） |

**这条差异是理解所有"仿真通过、真机不过"问题的钥匙。**

## 三、启动流程

真机：

```bash
bash scripts/robot_up.sh        # 一键起 driver → 等 joint_states → move_group/rviz → 执行节点
```

等价的手工步骤：

```bash
ros2 launch cello_moveit_config driver.launch.py            # ① 舵机驱动 + 控制器
ros2 launch cello_moveit_config actual_robot_demo.launch.py # ② rsp + move_group + rviz
ros2 launch cello_moveit_config arm_moveit_write.launch.py velocity_scaling:=0.05  # ③ 执行节点
```

仿真：

```bash
bash scripts/sim_up.sh          # demo(use_rviz:=false) + 执行节点 + 夹爪桥
```

**顺序要求**：① 必须先于 ②，否则 `robot_state_publisher` 收不到 `joint_states`，
算不出 `link6` 的 TF，所有到位校验都会报"TF 不可用"。

## 四、关键参数

| 参数 | 值 | 位置 |
|---|---|---|
| 速度缩放 | 0.1（yaml 默认）/ 0.05（真机实测用） | `joint_limits.yaml`，可被 `velocity_scaling:=` 覆盖 |
| 加速度缩放 | 0.1 | 同上 |
| IK 超时 | **0.05 s** | `kinematics.yaml` |
| 到位容差（末端） | 5 mm | `roarm_cli.py` |
| 到位稳定次数 | 连续 3 次进容差 | 同上 |
| 零位偏移 | +0.4, −0.2, −0.1, +1.3, −0.3, +0.8（度） | `robo_driver.ZERO_OFFSET_DEG` |
| 舵机稳态误差 | 0.6 ~ 0.8° | 实测，决定容差下限 |
