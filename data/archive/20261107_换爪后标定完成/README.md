## 夹爪标定的关键事实（下次换爪照这个流程）

1. **命令角 ≠ 读数角**：发 150° 只走到 114.9°，发 60° 只到 4.1°
2. **绝对角不可重复**：同一个 60° 两次起栈，一次闭合、一次张到最大
   → 所以 driver 改成 `target = grip_base_deg + deg`，
   `grip_base_deg` 在起栈时读一次并记下
3. **张开方向是负的**：基准（闭合）出发，+方向夹紧、−方向张开
4. **起栈前必须手动把两指拨到闭合**，因为基准就是那一刻的位置
5. **起栈时不驱动夹爪**（读当前位置原样发回），否则会绕整圈撞极限

## 夹住判据（重要）

`vision_pick` 里"误差 mm"指的是 **joint7_left 位移**，不是两指间距：

```
间距差 10mm → joint 位移 = 10 / 68 × 25 = 3.7mm
```

判据只看误差大小：`2 ≤ err ≤ 22` 判夹住、`< 2` 判抓空。
**不要用 `rc == 0` 判断**——物料挡住时 rc 也会是 0（2026-11-07 踩过）。
